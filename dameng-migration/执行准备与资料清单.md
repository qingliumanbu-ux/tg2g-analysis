# 后台 SQL 转换：执行范围与局部依赖

日期：2026-09-04。用户最新说明是当前工作依据：负责应用/后台 SQL 适配 DM8，使查询、新增、修改、删除等数据操作采用达梦支持的语法；数据库的数据和对象迁移由其他工作承担。

## 1. 本次交付

| 包含 | 处理方式 |
|---|---|
| 后台 SELECT、INSERT、UPDATE、DELETE、MERGE | 逐条核对 DM8 语法；保留条件、列映射、返回列、别名和业务结果 |
| 动态 SQL、字符串拼接及公共查询函数 | 检查生成后的 SQL，关联产生端和执行端；只改方言差异 |
| 函数、日期计算、分页、连接、空值处理、类型转换 | 按具体签名和语义判断；不能仅根据函数名批量替换 |
| 数据库分支、系统目录和序列引用 | 确保目标 SQL 合法，保留锁与错误控制流；未知平台映射只影响对应条目 |
| Web/C# 中送到后台执行的 SQL | 继续追踪并核对内嵌 SQL；不因此扩展成前端界面改造 |
| 配置中存放的 SQL、应用里的过程调用 | 有实际文本/签名即可适配；源码外尚未提供的 SQL 单独登记，不声称已转换 |

交付物是源代码中的 SQL 修改、每项转换依据、兼容保留记录，以及少量无法从源码判定的条目。保持原编码和换行，不重构无关业务。

## 3. 直接执行顺序

1. 使用现有全量扫描定位 SQL，区分业务代码、注释、声明和普通语言运算符。
2. 对照达梦官方文档，将具体表达式判为语法可保留、需转换或单项条件待确认。
3. 对能确定的差异直接做最小源码修改；逐项核对条件、参数、类型、单位、NULL 行为和控制流。
4. 记录原表达式、目标表达式、源码位置、依据与验证状态；继续处理下一项，不因局部未知暂停全量工作。

## 4. 只在需要时补充的信息

| 情况 | 仅需要的具体信息 |
|---|---|
| DM8 会进入哪个数据库分支无法由本地代码判断 | BM2 的 DatabaseKind 映射或枚举约定，不要求完整运行包 |
| 一条 SQL 依赖 NULL/空串、标识符或特定函数兼容设置 | 该项对应的 DM8 模式/设置，不要求搭建环境 |
| 元数据类型名称或字符/字节长度决定改写 | 对应字段/目录列的类型与语义，不索取全库结构和全部样本 |
| SQL 实际存放在配置表，源码只有读取入口 | 对应生效 SQL 文本及参数定义，不要求迁移该配置表 |
| 同名代码有多个版本且语句不同 | 标注版本差异；需要选择时再确认目标文件，不扩大成发布工程 |

## 5. 检查结果的含义

- 语法可保留：官方支持该写法，源码层面未发现必须转换的差异；不等于已在用户实例执行通过。
- 已转换、静态核查：代码已修改，检查过签名、方向、单位、业务条件和差异范围；实际数据库运行状态单独记录。
- 单项条件待确认：明确到哪条 SQL、缺哪个参数/类型/文本；其他条目继续推进。
- 待逐句审查：只是检索候选，不能记作已转换或确认兼容。

没有数据库运行条件时如实交付静态检查结果，不把它表述成达梦实例运行通过。运行测试可由后续负责测试的环境承接，不要求用户先承担数据库迁移。
