## 本轮发现并修复的工具问题

1. 扫描模式落后于转换规则(缺 SUBSTR2/current/标注时长等)→ 扫描模板更新为超集后全模块重扫重预览,仅漏网 2 块(fosmt00b substr2 已补;MMTP mat_track 为分支内目录查询按策略保留)。
2. `strSql2`/`querySql` 等变量名不匹配块检测 → 名称模式加入 `[Ss]trSql\w*`,全模块重预览捕获 18 块;追加块(`+=` 纯片段)不再要求含 SELECT 关键词。
3. Bash 工具会吞反斜杠导致 heredoc 补丁把 `\b` 写成退格符、`encode(enc)` 补丁静默失效 → 全部改用 Edit 工具/chr() 构造修复;补上了此前未生效的编码自适应写入(UTF-8 文件不再有写坏风险)。
4. 跨模块/跨轮次 CHANGE 编号冲突(PSSM 111×3、WM10×FOSMT 289—292/299)→ 全局重编号并终态校验 0 重复(337 个 CHANGE-NN,最大 339 区间内有空档属重编留痕,台账为准)。
5. 手工脚本头部冒号半角/全角不一致导致台账回溯失败 → 统一全角后重入账。
