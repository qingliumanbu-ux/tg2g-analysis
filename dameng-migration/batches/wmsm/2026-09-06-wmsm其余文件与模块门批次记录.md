## 保留判定要点(51 个文件、277 处保留型命中,逐一复核)

- 无 NULL 搜索值的 DECODE/decode:DM 支持(函数手册表 8.6),不依赖未记载语义。
- sysdate 与 `sysdate - 1/2`、`(date1-date2)*24`:DM 日期运算文档明确"日期可直接加减时、分、秒(1/24=1 小时)""两个 date 相减得到天数,乘以 24 即为小时"。
- `FETCH FIRST 1 ROWS ONLY`:DM 查询语句 `<ROW_LIMIT子句>` 明确支持。
- `seq.NEXTVAL`、LPAD、TO_CHAR、NVL、CASE、`rownum=1`/`rownum<6`、`to_char(ROWNUM)`、`WHERE ROWNUM=1`:官方支持用法。
- `FROM DUAl`(大小写混合):标识符不区分大小写,等价 DUAL。
- 空串比较(`OUT_STEEL_TIME = ' '`)仅出现在 SELECT 过滤,不涉及删除/更新集合扩大。

## 过程中发现并修复的工具问题

1. 块检测漏检:CString 类型前缀赋值(`CString sql = "SELECT…`)、无引号赋值行(`sqlstr =` 后换行续行)→ 放宽正则并加 SQL 关键词过滤。
2. find_call 大小写敏感导致小写 `decode(`/`days(` 漏检 → 加 re.I。
3. 跨文件 CHANGE 编号重复 → 全局重编:wmsm02_sg→85-94、wmsm01gg1→95-96、wmsmsm11→97、wmsm01q0q→98、wmsmpcgz→99、wm00_stockNo2→100-101、wmsmhrzc→102、wmsmrsl→103、cm_p3t801→104、cranecmd_update→105、wmsmsc_inq1→106(仅注释头标签,行数不变,台账已同步)。
4. 内联 SQL(直接传入 Db::QueryCString 等调用的字面量)不属 sql* 变量块 → 台账补 INLINE-* 行。
