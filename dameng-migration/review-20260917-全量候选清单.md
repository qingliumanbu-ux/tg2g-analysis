# 全量候选定位清单（2026-09-17）

## 0. 方法与口径（务必先读）

**做了什么**：对 `Server/**/*.cpp`（21 个模块、4,578 个文件）做了一次性完整模式覆盖，输出"哪个文件里有多少处可疑写法"。这一步保证**没有文件被漏检**。

**没做什么**：**没有**逐文件打开判读。因此本清单的"命中数"**包含 `//` 保留注释、`/* */` 块注释和历史副本里的内容**，命中数 ≠ 待改数。判读仍须逐文件进行——前几轮的 F-WMSM-01~04 与 12 处 `(+)` 都是靠打开文件才得出的，其中还纠正了 2 处假阳性（`f_pssm21_cast_cre_n.cpp` 的 `(+)` 实际在块注释内）。

**为什么这样分两步**：4,578 个文件里绝大多数没有 SQL 或没有方言。先定位，把作业面从 4,578 收敛到约 85 个文件，再逐个开文件判读——这是唯一能在合理时间内保证全覆盖的路径。

### 计数解读的重要更正

A 族式样中的 `AS INT\b` 本意是抓 `CREATE SEQUENCE … AS INT`，但它同时会命中**合法的 `CAST(x AS INT)`**。因此凡命中数里含 `CAST(... AS INT)` 的文件（如 `f_qmts_spe_sm.cpp`），**计数被系统性抬高**。解读命中数时须先扣除这一类，不能直接当工作量。
